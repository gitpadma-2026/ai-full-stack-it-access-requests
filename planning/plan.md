# Reviewed implementation plan

## Choices

- Runtime: Python 3.10+ with the standard library; zero third-party dependencies, so the dependency lock lists an empty dependency set.
- Interface: CLI backed by local SQLite; overlapping operators inspect committed rows while intake continues.
- Tests: `env -u API_KEY python3 -m unittest discover -s tests -v`; saved mocks and fake HTTP only.
- Provider: configurable OpenAI Responses API over HTTPS; mock mode by default, explicit live mode and `API_KEY` for real calls.

Review refinements: preserve raw bytes and immutable processing snapshots, include schema/prompt/policy/model in reuse identity, serialize claims with fencing tokens, retain failed attempts separately from prior successes, export one coherent snapshot, and separate mock correctness from live extraction accuracy.
