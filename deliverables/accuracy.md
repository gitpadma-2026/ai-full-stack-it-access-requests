These labels and saved replies were manually authored; matching mock labels is a pipeline check, not evidence of live language-model accuracy.

Each difference below is an exact-match difference with source evidence where applicable; a human must distinguish unsupported facts from equivalent wording. Review every claimed fact against decoded message text; count unsupported/wrong facts separately from omissions, report affected documents/fields, and retain the compared input hashes and configuration keys in extraction records. No live factual-error rate has been measured.
